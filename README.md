# Estudaí

Assistente de estudos que transforma textos e PDFs em resumo, flashcards e perguntas de revisão.

## Como usar

Abra `outputs/estudai.html` no navegador, cole um texto ou envie um PDF e clique em **Criar meu material**.

O processamento é feito no navegador. A leitura de PDF usa PDF.js via CDN.

## Estrutura

- `outputs/estudai.html`: protótipo completo em um único arquivo.
